# Wordle NeMo Gym Resources Server

Wordle game exposed as a [NVIDIA NeMo Gym](https://github.com/NVIDIA-NeMo/Gym) Resources Server.

**Endpoints:** `POST /guess`, `POST /get_history`, `POST /seed_session`, `POST /verify`

Part of the [exp_rl](https://github.com/adithya-s-k/exp_rl) project — demonstrating RL environment frameworks with TRL.
